# 去AI味编辑技能 — Humanizer-zh 6维度方法论

## 6维度检测规则

### D1: 内容模式（删废话/套话）
AI用大量空话填充内容，看似丰富实则无信息量。
- "在这个快速发展的时代" → 直接删除
- "赋能""助力""打造" → 替换为具体动词
- "重新定义了" → 用具体描述替代
- "不可否认""毋庸置疑" → 删除
- 情感标签化 → 用行为/生理反应展示
- 模板描写 → 用独特具体细节
- 排比句堆砌 → 拆散，取最有力的一个

### D2: 结构优化（拆长句）
AI句子长度过于均匀(CV<0.25)，句式单调。
- 连续3句以上相同句长(±5字)即为单调
- 穿插长短句，用破折号制造节奏变化
- 表情动作不要重复（嘴角微扬/眸中闪过 → 换成具体描写）
- 说话方式要多变

### D3: 语言语法（修语病病句）
连接词堆叠、语义重复、语法冗余。
- "而且，并且" → 只用一个
- "似乎…似乎""仿佛…仿佛" → 去掉一个
- "或许…也许""或许…可能" → 选一个
- "正因如此""正因为如此" → 删除或改为自然过渡

### D4: 翻译腔（去翻译腔）
AI输出像英文直译，中文母语者不会这样说。
- "值得注意的是""需要指出的是" → 删除
- "在这个过程中" → 删除
- "从某种意义上说" → 删除
- "综上所述""总而言之" → 网文不需要总结段落
- "这就是X的真谛" → 删除

### D5: 风格模式（调整体调性）
AI整体风格偏书面、偏文学，不够口语化。
- "然而"使用过多 → 变换为"不过""可是"或去掉
- "宛如""犹如" → 用"如同"或直接描写
- "时间流逝" → 换成具体事件标记时间

### D6: 填充词（删冗余表达）
AI用大量无信息量的词汇填充文本。
- "事实上""令人印象深刻" → 删除或替换
- "流露出""透露出""展现出" → 换成具体动作
- "不疾不徐""有条不紊" → 换成更口语的表达

## 替换策略
每个 AI 痕迹都要给出具体的替代方案，不能只是删除。
替换原则：保留原意 → 具体化 → 感官化 → 行为化 → 自然化。

## 人话标准
改完后大声读出来，不自然的地方继续改。
