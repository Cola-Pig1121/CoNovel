# Humanize Text — 6维度去AI化改写方法论

> 基于Humanizer-zh（GitHub 9.9k stars）的检测框架，针对中文AI生成文本的系统性去AI化方法。

## 核心理念

AI写出来的中文有一个共同特点：**看起来很"对"，但读起来不像人话。**

人类写作的特征：
- 句子长短不一，有呼吸感
- 用具体细节说话，不用抽象概括
- 情绪通过行为展示，不直接贴标签
- 口语化、有个性、偶尔不"完美"

AI写作的特征：
- 句子长度均匀（CV < 0.3）
- 大量空洞套话和模板表达
- 翻译腔重，像英文直译
- 喜欢总结、喜欢排比、喜欢"元评论"

## 6维度检测与改写

---

### D1: 内容模式（删废话/套话）

**问题**：AI用大量空话填充内容，看起来很丰富，实际没有信息增量。

#### 必删模式

| AI腔 ✗ | 处理 ✓ | 说明 |
|--------|--------|------|
| 在这个快速发展的时代 | 直接删除 | AI最爱的开场白，毫无信息量 |
| 在这个瞬息万变的世界里 | 直接删除 | 同上 |
| 重新定义了内容创作 | 改为"改变了内容创作" | 说人话 |
| 赋能中小企业 | 帮助中小企业 | "赋能"是AI/商业黑话 |
| 助力经济发展 | 促进经济/帮了经济一把 | 同上 |
| 打造了一个平台 | 做了一个平台 | "打造"过犹不及 |
| 深耕行业多年 | 干了这行很多年 | 同上 |
| 不可否认，这很重要 | （删除，直接说观点） | 不需要"不可否认" |
| 这就是幸福的真谛 | 直接删除 | 空洞总结 |

#### 情感标签化 → 行为展示

```
✗ 他感到一阵恐惧涌上心头。
✓ 他的手开始发抖，后背一阵发凉。

✗ 她心中充满了喜悦。
✓ 她嘴角翘了起来，脚步都轻快了。

✗ 一种难以言喻的感觉弥漫开来。
✓ 他愣在原地，半天说不出话。
```

#### 模板描写 → 独特细节

```
✗ 月光如水，洒在窗前。
✓ 路灯把树影拉得老长，投在墙上像一只只手。

✗ 星光璀璨，夜空如洗。
✓ 天上只有两三颗星，灰蒙蒙的。

✗ 空气中弥漫着紧张的气氛。
✓ 三个人谁也不说话，只有钟在滴答走。
```

#### 排比句堆砌 → 拆散取最有力的一个

```
✗ 这不仅是技术的革新，更是思维的颠覆，还是时代的呼唤。
✓ 这玩意彻底改变了人们的做事方式。
```

---

### D2: 结构优化（拆长句）

**问题**：AI句子长度过于均匀，缺乏人类写作的节奏感。

#### 检测方法
- 计算所有句子的长度，求变异系数(CV)
- CV < 0.25 = 大概率AI生成
- 检查句首重复率：同句首 > 30% = 需要改

#### 改写技巧

**1. 穿插短句制造节奏感**
```
✗ 他走进了那间已经很久没有人来过的办公室，发现桌上落满了灰尘，椅子歪倒在一边，窗户半开着，窗帘在风中轻轻摇晃。
✓ 他推开门。办公室落满了灰。椅子歪着，窗帘在风里晃。
```

**2. 用破折号/省略号打断均匀节奏**
```
✗ 他看着她离开的背影心中五味杂陈不知该说什么好。
✓ 他看着她走远——该说什么呢？算了。
```

**3. 表情动作不要重复**
```
✗ 她嘴角微扬，眸中闪过一丝光芒，淡淡地笑了。
✓ 她笑了，眼睛弯成月牙。
```

**4. 说话方式要多变**
```
✗ "你好。"他轻声说道。
✗ "不错。"她缓缓开口。
✗ "嗯。"他沉声道。
✓ "你好。"
✓ 她点点头："不错。"
✓ "嗯。"他没抬头。
```

### D3: 语言语法（修语病病句）

**问题**：连接词堆叠、语义重复、语法冗余。

#### 必修模式

```
✗ 而且，并且需要考虑 → 而且需要考虑
✗ 因此，所以他就去了 → 所以他就去了
✗ 但是，不过情况有变 → 但是情况有变
✗ 然而，但是结果不同 → 然而结果不同
```

#### 语义重复

```
✗ 他似乎似乎在犹豫 → 他似乎在犹豫
✗ 仿佛仿佛一场梦 → 仿佛一场梦
✗ 或许也许明天吧 → 或许明天吧
```

#### 模板因果

```
✗ 正因如此，他决定出发。
✓ 他决定出发。
（不需要说"正因如此"，因果关系在上下文中已经清楚）
```

---

### D4: 翻译腔（去翻译腔）

**问题**：AI输出像英文直译，中文母语者不会这样说。

#### 必删模式

| AI腔 ✗ | 处理 ✓ |
|--------|--------|
| 值得注意的是，… | 删除，直接说 |
| 需要指出的是，… | 删除 |
| 事实上，… | 删除 |
| 在这个过程中，… | 删除 |
| 从某种意义上说，… | 删除 |
| 这使得他… | 他因此… / 直接写结果 |
| 这导致了… | 导致了… / …因此… |
| 综上所述，… | 删除（网文不需要总结段落） |
| 总而言之，… | 删除 |
| 不难看出，… | 删除 |
| 由此可见，… | 删除或改为"于是" |
| 毫无疑问，… | 删除 |
| 就在这时，… | 改为具体场景切换 |

#### 翻译腔结构

```
✗ It is worth noting that the weather was nice. → 值得注意的是，天气很好。
✓ 天气不错。

✗ This led to a significant change in his life. → 这导致了他生活中的重大变化。
✓ 他的生活从此变了样。
```

---

### D5: 风格模式（调整体调性）

**问题**：AI整体风格偏书面、偏文学、偏"正确"，不够口语化。

#### 改写要点

```
✗ 然而，他依然选择了坚持。
✓ 不过他还是撑了下来。

✗ 宛如一幅画卷展开在眼前。
✓ 像画一样好看。

✗ 时间悄然流逝，转眼已是三年。
✓ 一晃三年过去了。
```

#### 网文风格标准
- 对话要口语化："你好"比"您好"更自然（除非角色设定）
- 不需要每段都有"总结句"
- 转折不要太"正式"，可以用"可是""不过"甚至不用
- 成语四字词不要堆砌，一个段落最多用1-2个

---

### D6: 填充词（删冗余表达）

**问题**：AI用大量无信息量的词汇凑字数。

#### 必删/替换清单

| 填充词 ✗ | 处理 ✓ |
|---------|--------|
| 事实上 | 删除 |
| 令人印象深刻 | 用具体描写替代 |
| 难以置信 | 用具体反应替代 |
| 流露出微笑 | 笑了 |
| 透露出一丝 | （删除或换成"有"） |
| 展现出强大的 | （删除或换成具体形容词） |
| 散发出温暖的 | （删除或换成"暖"） |
| 不疾不徐地走 | 不紧不慢地走 / 慢悠悠地走 |
| 有条不紊地说 | 有条理地说 / 直接写说了什么 |
| 不觉间 | 不知不觉 |
| 自然而然地 | 直接删除 |

## 改写流程

### Step 1: 快速扫描
读全文，标记AI腔明显的句子（通常前3句就能判断）。

### Step 2: D1+D4优先处理
先删掉最明显的空话和翻译腔——这是改动量最大、效果最明显的。

### Step 3: D3+D6清理
修连接词、删填充词——这些改动小但积累效果好。

### Step 4: D2结构调整
拆长句、换句首、加节奏感——需要通读全文才能做好。

### Step 5: D5风格统一
最后调整整体调性，确保全文一致。

### Step 6: 大声读
改完后大声读出来。不自然的地方自然会暴露。

## 质量检查清单

改完后逐项确认：
- [ ] 没有"在这个…的时代"之类的AI开场白
- [ ] 没有"值得注意的是""需要指出的是"等翻译腔
- [ ] 没有"赋能""助力""打造"等AI黑话
- [ ] 情绪是通过行为/反应展示的，不是"感到X"
- [ ] 句子长短有变化，不是都差不多长
- [ ] 连接词没有叠加使用
- [ ] 没有排比句堆砌
- [ ] 大声读出来不别扭
