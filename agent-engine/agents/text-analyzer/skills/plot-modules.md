# 情节模块提取方法论

## 模块分类体系

### A类——结构性模块（支撑故事骨架）

**A1: 开局模块**
| 模块名 | 描述 | 适用场景 |
|--------|------|----------|
| 身份反转开局 | 主角从高位跌落或从低位崛起 | 逆袭/重生题材 |
| 危机降临开局 | 主角被抛入紧迫危机 | 悬疑/生存题材 |
| 金手指揭示开局 | 展示主角特殊能力/系统 | 系统流/异能题材 |
| 世界揭秘开局 | 逐步揭开世界观的冰山一角 | 世界观宏大的题材 |
| 日常切入开局 | 从平凡生活切入，渐入异常 | 都市/现实题材 |
| 悬念倒叙开局 | 从高潮/结局片段倒叙 | 悬疑/推理题材 |

**A2: 冲突构建模块**
| 模块名 | 描述 | 适用场景 |
|--------|------|----------|
| 阶梯式冲突 | 敌人/困难逐级增强 | 升级流/成长题材 |
| 两难抉择冲突 | 主角面临不可兼得的选择 | 情感/道德题材 |
| 信息不对称冲突 | 角色间的信息差制造张力 | 悬疑/权谋题材 |
| 倒计时冲突 | 有限时间内必须完成任务 | 紧张节奏需求 |
| 背叛冲突 | 信任关系被打破 | 人物关系驱动 |
| 多线交汇冲突 | 多条线索在同一节点碰撞 | 复杂群像题材 |

**A3: 高潮模块**
| 模块名 | 描述 | 适用场景 |
|--------|------|----------|
| 力量爆发高潮 | 积蓄已久的力量终于释放 | 热血/战斗题材 |
| 真相揭露高潮 | 关键信息被揭开 | 悬疑/推理题材 |
| 牺牲换生高潮 | 通过牺牲获得胜利 | 情感高潮 |
| 逆转高潮 | 局势180度反转 | 反转密集型题材 |
| 对峙高潮 | 两强正面对决 | 战斗/权谋题材 |
| 抉择高潮 | 做出改变命运的选择 | 人物成长节点 |

### B类——衔接模块（保持叙事流畅）

**B1: 过渡模块**
- 时间跳转过渡（快进/慢放）
- 空间切换过渡（场景转换）
- 情绪承接过渡（上一章情绪延伸到下一章）
- 信息桥接过渡（通过一个信息点连接两个场景）
- 日常插入过渡（在紧张段落后插入日常调节）

**B2: 信息投放模块**
- 对话中嵌入信息（通过角色交谈传递）
- 环境描写中嵌入信息（场景细节暗示信息）
- 内心独白中嵌入信息（主角思考时带出）
- 事件驱动信息（通过事件自然暴露信息）
- 回忆闪回信息（通过回忆补充背景信息）

### C类——钩子模块（驱动读者继续阅读）

**C1: 章末钩子**
- 悬念中断（在紧张处戛然而止）
- 反转预告（暗示即将发生意外）
- 新角色登场（引入引发好奇的新角色）
- 信息碎片（透露部分信息，留有关键空白）
- 危机预兆（暗示危险即将到来）
- 承诺钩子（承诺下一章将有精彩内容）

**C2: 章内钩子（微钩子）**
- 对话暗示（角色话语中的弦外之音）
- 细节异常（某个不寻常的细节）
- 内心动摇（主角产生疑虑或不安）
- 环境异变（环境出现反常变化）

## 模块组合规则

### 节奏公式
- **快节奏组合**：A2(阶梯) + C1(悬念中断) + A3(逆转) + C2(微钩子)
- **慢节奏组合**：A1(日常切入) + B1(情绪承接) + B2(环境嵌入) + C2(细节异常)
- **悬疑组合**：A1(悬念倒叙) + A2(信息不对称) + C1(信息碎片) + B2(回忆闪回)
- **热血组合**：A1(金手指揭示) + A2(阶梯式) + A3(力量爆发) + C1(反转预告)

### 模块禁忌
- 高潮模块不宜连续使用（至少间隔3章）
- 悬念中断钩子不宜超过3章不给解答
- 信息投放不宜过于密集（每章最多2个新信息点）
- 过渡模块不宜过长（不超过1章）
- 倒叙使用不超过全文10%

## 评分标准
每个模块的有效性评分（1-5分）：
- 5分：该模块显著提升了阅读体验，读者反馈明确正面
- 4分：模块效果良好，自然融入叙事
- 3分：模块效果中规中矩，无明显问题
- 2分：模块效果一般，有改进空间
- 1分：模块效果不佳，可能引起读者反感
