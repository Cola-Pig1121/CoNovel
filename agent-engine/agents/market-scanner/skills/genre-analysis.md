# 题材分析方法论

## 分析流程

### 第一步：热度判定
从榜单数据中提取题材维度的聚合指标：
- 上榜作品数量占比
- 头部作品的平均追读/收藏量
- 近30天新增同类作品数量
- 评分中位数（反映读者满意度基线）

热度等级映射：
- 🔥🔥🔥🔥🔥 现象级（多个平台同时霸榜）
- 🔥🔥🔥🔥 高热度（单平台多部上榜）
- 🔥🔥🔥 中等热度（稳定上榜但无爆发）
- 🔥🔥 低迷（零星上榜）
- 🔥 冷门（几乎不见踪影）

### 第二步：趋势判断
对比近期数据与历史数据的变化：
- 上榜数量增长 → 上升趋势
- 上榜数量持平 → 稳定期
- 上榜数量减少 → 下降趋势
- 新人作品占比高 → 新鲜血液充足，赛道仍有空间
- 老牌作者垄断 → 进入门槛高，新人难突围

### 第三步：成功模式提取
针对热度 ≥🔥🔥🔥🔥 的题材，分析头部作品的共性：

**结构模式**：
- 章节数量级（百万字级/三百万字级/五百万字级）
- 卷章节奏（快卷快结 vs 长线铺陈）
- 战力体系层级数

**钩子模式**：
- 开篇钩子类型分布
- 章末悬念手法统计
- 爽点间隔（平均每N章一个高潮）

**人设模式**：
- 主角类型分布（逆袭型/成长型/无敌型/智谋型）
- 女主/女性角色设计趋势
- 配角功能分配

### 第四步：读者偏好提炼
综合评分和评论数据分析：
- 高分作品的共性特质
- 低分作品的常见问题
- 读者评论中的高频关键词
- 读者明确表达的期待和不满

### 第五步：机会评估
综合以上分析给出：
- 该题材是否适合当前项目
- 差异化切入角度建议
- 需要规避的同质化陷阱
- 建议的字数体量和更新节奏
