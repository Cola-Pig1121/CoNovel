# CoNovel Template

This is a template for creating new CoNovel book presets.

## Structure

```
_template/
├── README.md           # This file
├── writing-techniques.csv   # Genre-specific writing techniques
├── plot-structures.csv      # Plot structure templates
├── emotion-design.csv       # Emotion design patterns
└── agents/                  # Customized agent system prompts
    ├── narrative_writer.md
    ├── reviewer.md
    └── ...
```

## How to Use

1. Copy this template directory
2. Rename it to your genre/style name
3. Customize the CSV files for your genre
4. Customize agent prompts for your style
5. Place in `store-presets/` or share via GitHub
